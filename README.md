# WeightTrackApp
# Weight Tracker Mobile Application

## Project Overview

For this project, I developed a weight-tracking mobile application using Java and Android Studio. The goal was to create an application that allows users to record their daily weight, track their progress, and set personal weight goals. The application was designed to provide a simple and organized way for users to manage their weight information while keeping the interface easy to navigate.

## 1. User Needs and Application Goals

The main goal of my application was to help users keep track of their weight and progress toward personal goals. Users needed a way to create an account, log in, enter their daily weight, and manage their records. I wanted the application to be straightforward so users could focus on tracking their progress without having to navigate a complicated interface.

## 2. UI Design and User-Centered Features

I designed the application with login, weight-tracking, and settings screens. The login screen allows users to enter their account information, while the tracking screen provides fields for recording daily weights and setting a goal weight. The settings design also includes an option for SMS reminders.

When designing the interface, I focused on keeping the layout organized, using readable labels, and making buttons easy to identify. I chose a light pink background with bright pink buttons and other soft colors to create a consistent appearance. I believe the design was successful because it organized the main features into clear sections and made the application's purpose easy to understand.

## 3. Coding Approach and Development Strategies

I approached coding the application by working on one feature at a time instead of trying to complete everything at once. I started with the UI designs from Project Two and then worked on connecting the interface to Java code in Project Three.

I implemented the login functionality, input validation, navigation between activities, and weight-entry features. I also worked with a database helper class to support storing application information. Throughout development, I used Android Studio's build feedback to identify errors and make corrections. This process taught me the importance of breaking larger projects into smaller tasks, a strategy I plan to continue using in future software development projects.

## 4. Testing and Functionality

To test my application, I used Android Studio's build tools to check for compilation errors and reviewed the code as I completed different features. I corrected issues involving component IDs, variable references, and connecting Java code to the appropriate UI elements.

Testing helped me recognize that even small differences between an XML component ID and its Java reference can prevent an application from building correctly. This reinforced the importance of checking code carefully, testing features throughout development, and resolving problems before moving forward.

Although I successfully built the project, I was not able to complete full emulator testing, so additional runtime testing would be an important next step.

## 5. Challenges and Innovation

One of the biggest challenges I encountered was connecting my XML layouts to the Java functionality. While the interface was already designed, making the buttons, input fields, and activities work together required additional problem-solving.

I ran into errors when some component IDs did not match the references in my Java code. Instead of restarting the project, I reviewed the XML layouts, compared the IDs with my Java code, and corrected the mismatches. This experience taught me to troubleshoot problems systematically and understand how different parts of an Android application depend on one another.

## 6. Demonstrating My Skills

I am particularly proud of the progress I made implementing the application's login and weight-entry functionality. These features allowed me to apply Java programming concepts, event handling, input validation, and Android UI development to a practical project.

This project also helped me understand how important it is to consider the user throughout the entire development process. I gained more confidence working with Android Studio and learned how to take an application from an initial design toward a functional product.

Overall, developing the Weight Tracker application strengthened my understanding of mobile application development, debugging, and user-centered design. It also gave me another opportunity to apply my Computer Science coursework to a project that I can continue improving in the future.
